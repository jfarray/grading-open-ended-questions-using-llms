# Grading open-ended questions using Llms and RAG
This repository contains the code used for the experiment on numerical grading of open-ended questions with answers of approximately 250 words using LLMs and the retrieval augmented generation (RAG) technique. This experiment used the Cohere, Gemini, and Llama3 models, running all code locally due to privacy policies.

## Prerequisites
- An environment to run the Python notebook.
- API keys for Cohere and Gemini LLMS.
- [Ollama](https://ollama.com/) installed to use LLama3 LLMS.
